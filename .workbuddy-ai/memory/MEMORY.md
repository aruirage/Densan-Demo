- **設定系ページ（`#page=security` 等）は `maincol` の内側でスクロールさせる**：`.maincol` は `height:calc(100vh - 155px)` + `overflow:hidden` なので、内容が高いページは戻り値全体を `div`（例 `div.sec-page`）で包み `flex:1 1 auto;min-height:0;overflow:auto` を付ける。付けないと下部のボタンが切れて押せない。

- **デモの権限モードは `demo/admin-mode.js` が握る**。既定で `window.DEMO_FULL_ADMIN = true`（＝全システム・全メニュー権限）。`?perm=1` を付けたときだけ制限あり。`index.html` で **app.js より前に**読み込むこと。
- **`isTenantAdmin()` は `window.DEMO_FULL_ADMIN` を最優先で見る**。ここ 1 箇所で メニュー到達（`menuLeavesForUser`→null）／帳票権限（`canTicketAct`）／アップロード権限（`canUploadBiz`）／操作権限（`userHasOp`）／データ権限（`dataPermOf`）がまとめて素通りする。`review-focus-fix.js` 側は `adminMode()` が同じフラグを見て `visibleLayouts()` を null にする。
- **app.js の `let`/`const` は window に生えない**（classic script の top-level 宣言）。`review-focus-fix.js` から `window.GROUPS` を読んでも `undefined`。外部ファイルから内部データを使うときは `window.__demo` に**明示的に export** するか、`assigneeUserIds()` のような公開ヘルパに委譲する。
- **`ENT_USERS` の照合は `uid`**（`id` は `'U1'`、`state.currentUser` は `'u1'`）。`u.id === uid` と書くと必ず false になる。
- **`review-focus-fix.js` の `killActorSwitcher()` がデモ用 UI を DOM から削除する**：`.userpick` 配下の `.usermenu-switch` / `[data-demo-actor]` / `.demo-badge` は MutationObserver で描画直後に `remove()` される。ヘッダーに何か足しても消えるので、可視化したいときはコンソール出力など DOM 以外の手段にする。
- **デモのモードはコンソールに出る**：`admin-mode.js` が `[demo] 権限モード：…` を `console.info`。既定＝全権限、`?perm=1`＝制限。
