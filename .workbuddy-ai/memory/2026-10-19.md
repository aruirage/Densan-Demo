## 権限切替ボタンがクリックで反応しない件（capture で解決）

- 症状：`.ds-btn` を実クリックしても `state.currentUser` が変わらない。`element.onclick(...)` を
  直接呼ぶと変わる。`dispatchEvent(new MouseEvent('click'))` でも listener が発火しなかった。
- 原因：document の capture 時点で `event.defaultPrevented === true`。画面側のクリック処理が先に走り、
  ボタンまでイベントが届いていない（`preventDefault` 済み）。
- 対応：`window.addEventListener('click', handler, true)` で `[data-demo-actor]` を拾い、
  `preventDefault` + `stopPropagation` してから切替える（`bindDemoActorOnce()`、1 回だけ登録）。
  要素ごとの `onclick` は残すが、実クリックは capture 側で処理される。
- 教訓：デモ用の常設 UI は「要素に onclick を貼る」だけでは足りない。全体のクリック処理に
  食われるので、window capture で委譲する。

## 監視パスを複数化し、テナント切替を撤去（自動アップロード）

- ユーザー指示：「複数テナントの切替は不要。監視パスは複数入力でき、それぞれ有効／無効を切替える。
  1 監視パス＝1 仮想マシン上のフォルダ」。
- `WATCH.tenant` と `watchTenantName()` を削除（テナント切替 UI は画面から消えた）。
  「取込先」セクションは「帳票タイプ」1 項目だけに。

  filesv03 世帯異動、3 行目は off）。UI は `.watch-paths > .wp-row`。
- 行内操作：`data-watchpath`（oninput 即時反映）／`data-watchpathon`（行トグル）／
  `data-watchpathdel`（×、残り 1 行のとき disabled）。`data-watchpathadd` で空行を追加。

- CSS は `.wp-row` を flex 1 行（input 伸長＋34×20 の小トグル＋24×24 の ×）。
  off 行は `background:#f6f7fa` でグレーアウト。`.wp-del:disabled{opacity:.35}`。
- テスト追加：`テナント` が HTML に無いこと、`.wp-row` 数 = `WATCH.paths.length`、
  `data-watchpathon` 数も同数、`data-watchpathadd` の存在。58 pass。

- 教訓：`serve.py --build dist` の静的ファイル白名単に CSS を足し忘れると、公開サイトだけ
  スタイルが崩れる（`dict-watch.css` で実際に踏んだ）。CSS を新設したら白名単を確認する。

### 罠：`.wf-note` / `.grp-note` は serve.py が HTML コメント化する

## 自動アップロード：左右 2 段組みをやめて 1 カラムに

- 「左右のレイアウトはやめて、もっと良い実装を」との指示。
